# MODELROGS project family

## MODELROGS is the umbrella name

MODELROGS is the common identity for a family of firmware projects for smart displays. It is the umbrella project name, not a firmware that sits above the others in a technical inheritance hierarchy.

## Projects at the same level

The first firmware project released under the MODELROGS name is **MODELROGS TEMPO**. **MODELROGS DISPLAY** is a separate project in the same family.

```text
MODELROGS  ·  Umbrella name / project family
│
├── MODELROGS TEMPO    ·  First firmware project
│
└── MODELROGS DISPLAY  ·  Separate firmware project
```

TEMPO and DISPLAY are peers. DISPLAY is not a child, fork or derivative of TEMPO, and TEMPO is not the parent of DISPLAY. Each project has its own repository, firmware, documentation, roadmap and release cycle.

## Repositories

- **MODELROGS TEMPO:** this repository.
- **MODELROGS DISPLAY:** https://github.com/Sqweedly/modelrogs-display

The two projects share the MODELROGS identity. Any shared code or technical dependency should be documented explicitly if and when it exists; the common name alone does not imply code inheritance.
